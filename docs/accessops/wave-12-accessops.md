# Wave 12 AccessOps

AccessOps adds a civic access digital twin for assets, feature observations, operational status, reliability, incidents, work orders, sensors, partner APIs, and open-data projections.

Mandatory boundaries:

- Accreditation is not live operational status.
- Missing data is not treated as accessible.
- Stale data is not treated as current.
- Sensors are sensing-only; AccessOps performs no actuation.
- Routes are advisory and retain uncertainty.
- Participant journeys are not shown on civic or admin dashboards.
