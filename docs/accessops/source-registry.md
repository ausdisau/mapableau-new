# Source registry

Every imported AccessOps record identifies an `AccessDataSource`.

## Rules

- Licences and attribution are enforced.
- Endpoints are allowlisted.
- Trust is data-type specific, never universal.
- Stale thresholds are source specific.
- Sandbox and production sources are separate (`productionActivated` default false).
- No protected-source scraping; no import without lawful-use assessment.
