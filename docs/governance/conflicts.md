# Conflicts and recusal

Conflict handling applies to reviewers, decision-makers, panel members and
administrators.

Rules:

- Declarations identify subject, context type, context ID and recusal requirement.
- Required recusals block reviewer assignment and appeal decisions.
- Conflict checks must be explicit before independent review.
- Recusal is protective governance, not a disciplinary finding.
- Conflicts are not published with participant data.

Conflict controls support trust in reviews; they do not certify system fairness.
