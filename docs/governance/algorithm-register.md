# Algorithm register

The algorithm register is a public-safe explanation layer for governed systems.
It names the system, owner, purpose, affected people, human review, limitations
and challenge pathway.

Rules:

- A register entry is not certification, endorsement or regulatory approval.
- High-impact publication requires an approved or conditional AIA.
- Public copy must not claim a system is bias-free, risk-free or fully compliant.
- Public payloads are redacted for secrets, prompts, participant data, fraud thresholds and exploit details.
- Dry-run backfills may plan entries, but must not publish automatically.

The register supports transparency and challenge; it does not approve deployment
or replace operational controls.
