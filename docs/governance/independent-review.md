# Independent review

Independent review protects appeals from the original decision-maker deciding
their own work.

Reviewer rules:

- Reviewer user ID must differ from the decision owner.
- Conflict checks are mandatory before assignment.
- Active recusal declarations block assignment or decision.
- Findings must record outcome and rationale.
- Review completion is not certification of the original system.

Outcomes may uphold, overturn, vary or remit a decision. Remedies are separate
tracked actions.
