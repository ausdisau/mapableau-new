# MapAble Suburb Guide Verification Model

MapAble suburb guides use transparent confidence labels so users can judge how much trust to place in the information.

## Statuses

| Status | Public meaning |
|---|---|
| Draft guide | Created from templates and starter data. Needs local checking. |
| Data-enriched | Includes public/open datasets such as suburb boundaries, transport stops, toilets or public facilities. |
| Community reported | Includes one or more user or volunteer updates. |
| Partner supplied | Includes data supplied by a council, venue, provider or community partner. |
| MapAble reviewed | Reviewed by MapAble using submitted evidence, photos or trusted data. |
| MapAble verified | Checked through a MapAble assessment or verification workflow. |
| Needs local verification | Important details remain unconfirmed. |

## Public disclaimer

MapAble guides provide practical access information to help people plan outings. They are not a guarantee of access and are not legal, medical, transport or NDIS advice. Conditions can change. Check opening hours, bookings, transport availability and venue accessibility before travelling.

## Publishing rule

Do not index thin draft pages. A suburb guide should only be indexable when it has enough practical value, such as verified or data-enriched notes for transport, toilets, public places, and local planning risks.

## MapAble Accreditation relationship

Suburb guides can reference MapAble Accreditation where a venue has been assessed, but suburb guide status is not the same as venue accreditation. A suburb guide may be data-enriched while individual venues remain unverified.
