# Privacy and security

## Minimisation

Tools receive minimum fields for the task. Full passports are not sent to models by default.

## Sharing

Trust Kernel enforces purpose, recipient, fields, approval, revocation, and audit.

## Tenancy

Venue Operate/Verify require organisation/staff assignment or platform admin. Demo role headers ignored when demo mode is off.

## Content trust

Venue text and uploads are untrusted content — not agent instructions (prompt-injection resistance).

## Limitations

- Demo entitlement repository until Stripe AI plans exist  
- Consent grants currently in-memory in demo  
- No claim of NDIS practice standard certification
