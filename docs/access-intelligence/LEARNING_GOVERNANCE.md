# Learning Lab governance

Access Intelligence Learning Lab is didactic. It must not weaken production safety rules.

## Non-negotiable boundaries

| Rule | Enforcement |
|------|-------------|
| Lessons optional | Plan mode at `/access-intelligence` remains available without progress |
| Deterministic decisions | Fit / route engines unchanged by Learning Lab tools |
| Route eligibility | Learning tools do not rewrite production route graphs |
| Unknowns stay unknown | Evidence status `unknown` is never upgraded to fact by LM or rubrics |
| No capacity inference | Scenarios and teach-back reject inferring cognition from disability markers |
| No formal competence | Teach-back feedback states formative-only; no professional certification |
| No silent publish | Author drafts unpublished until accessibility + lived-experience approval |
| No public leaderboards | Progress API returns concept mastery only; `leaderboard: null` |

## Language model role

May: narrate, explain steps, give graduated hints, adapt presentation.

Must not: change access decisions, change eligibility, invent facts, infer capacity, award competence, or publish unreviewed content.

## Rubric dimensions (deterministic)

1. Requirement recognition  
2. Evidence reasoning  
3. Uncertainty handling  
4. Route and contingency planning  
5. Consent, rights, privacy, and communication  

## Review & provenance

Published scenarios store author, accessibility reviewer, lived-experience reviewer, optional professional reviewer, jurisdiction, version, review date, and source material. Prefer lived-experience and accessibility scrutiny before workforce distribution.

## Privacy

Facilitated sessions default to **anonymous responses**. Accessible exports omit ranking and public comparison.
