# Pilot and Evaluation Console

**Route:** `/access-intelligence/pilots`  
**API:** `GET /api/access-intelligence/pilots` (`?id=` · `?export=`)  
**Data:** `lib/access-intelligence/pilots/demo-pilot.ts` (synthetic)

## Views

- Cohorts and organisation partners (fictional)  
- Predicted vs observed journey outcomes  
- Learning, evidence-quality, venue-ops measures  
- Safety gates (unauthorised share, model override, approvals, audit)  
- De-identified JSON export (no emails, names, or passport fields)  

## Hard rule

Do not claim research validity, population outcomes, or regulatory approval from demo metrics.
