# Pilot runbook

## Planned event

Starting a new job (`start_job`) — Harbour Civic Centre style dependencies.

## Failure

Accessible transport cancellation ~70 minutes before first day.

## Stages

1. Life-event mission setup  
2. Dependency confirmation  
3. Resilience review  
4. Simulated cancellation  
5. Shadow failure detection  
6. Recovery-option review  
7. Human coordination  
8. One participant-approved service action (supervised only)  
9. Recovery receipt  
10. Outcome and friction review  

## Kill criteria

Participants confuse simulated vs confirmed; Stop fails; hard requirements weakened; FV safety unprotected; model gains execution authority.
