# ContinuityOS Pilot Runbook

## Planned event

**Starting a new job** (`start_job`) — Taylor-style fixture at Harbour Civic Centre.

Fixture: `data/continuity-os/pilot/start-job-transport-cancel.json`

## Failure playbook

**Accessible transport cancellation** ~70 minutes before first day.

## Stages

1. Create life-event mission (draft)  
2. Confirm dependencies / preserve unknowns  
3. Resilience review  
4. Simulate transport cancellation (shadow)  
5. Review options (exclude inaccessible replacement)  
6. Human coordination option available  
7. Select option → prepare proposal (no auto execute)  
8. Record outcome / receipt  
9. Review friction (system burden only)

## Kill criteria (abort pilot)

- Participants confuse simulated vs confirmed availability  
- Stop does not halt workflows  
- Hard access requirements weakened  
- Family-violence safe mode contacts unsafe supporter  
- Model gains execution authority  

## Measures

Comprehension, dependency accuracy, unknown preservation, recovery time, choice, fields disclosed, false recovery, friction, human workload, accessibility barriers, trust.
