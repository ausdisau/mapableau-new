# Life event taxonomy

Versioned registry in `lib/continuity-os/taxonomy/registry.ts` with Prisma mirrors `LifeEventType` / `LifeEventTypeVersion`.

## Categories

EDUCATION · EMPLOYMENT · HOME_AND_COMMUNITY · HEALTH_AND_SUPPORT · FAMILY_AND_IDENTITY · SCHEME_AND_SERVICE

## First pilot type

`start_job` @ version `1.0.0`

Includes dependencies for workplace entrance, lift, first-day adjustment, accessible transport, morning support worker, equipment charger, arrival deadline, employer contact and communication mode.

## Governance

- Supersession creates a new version; prior versions retained
- Templates never presume identical steps for every person
- Policy source keys recorded; draft reforms not encoded as settled law
- Human review owner on each type

## Activation

Only participant (or valid authority grant) may activate. Models may suggest type only.
