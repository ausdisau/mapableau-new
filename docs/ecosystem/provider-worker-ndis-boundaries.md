# Provider Finder, worker screening and NDIS guidance boundaries

## Keep separate

| Concept | Authority |
| --- | --- |
| Provider registration | Official NDIS Commission / directory evidence |
| Individual worker screening | Authorised NDIS Worker Screening pathway only |
| Public compliance / enforcement | Official publications |
| Professional qualifications | Evidence-specific |
| Availability / suitability | Not proven by registration alone |
| Participant experience | Distinct from registration |

## Display rules

- When live screening evidence is unavailable, show **Not independently verified**.
- Never invent an individual’s clearance status.
- Never treat a registered organisation as proof that every worker is cleared.
- Do not introduce a single “safe worker” or “NDIS-approved seller” score.

## NDIS Advisor / guidance

Optional, clearly labelled informational guidance only. Distinguish product characteristics, support categories, current rules/exclusions, plan considerations, provider statements and evidence requiring confirmation.

Never claim automatic NDIS funding, prescribing authority or eligibility. AI-generated advice must not submit claims or override participant choice.
