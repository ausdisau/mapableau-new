# AURA Wave 2 — Bounded Plan Challenge

One automatic structured challenge cycle per plan version. No recursive self-deliberation. No chain-of-thought storage.

## Checks (deterministic)

1. Falsifying evidence
2. Weakest required evidence
3. Preferred route failure
4. Remaining assumptions
5. Lower-disclosure option
6. Standard non-AI route
7. Hard requirement weakening
8. Live conditions currency
9. Human confirmation still required

Model may draft human-readable explanations; check status is deterministic.
