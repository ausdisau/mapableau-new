# Physical Safety Case (Wave 10)

## Claim

In demo/shadow mode, MapAble AURA cannot cause physical harm because:

1. Model has no device tools
2. Safety Kernel is deterministic and non-overridable by the model
3. Prohibited capabilities are immutable
4. Emergency and kill switches fail closed
5. Success requires postcondition evidence
6. Robot missions are labelled simulated
7. Production mode is disabled by default
