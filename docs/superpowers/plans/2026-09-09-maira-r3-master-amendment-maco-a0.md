# MAIRA R3 Master Plan Amendment — MACO Phase A0

**Status:** Proposed amendment to the approved MAIRA R3 master implementation plan.

## Decision

Insert **MACO Phase A0 — Consciousness Observatory Foundation** before MAIRA Phase A for all consciousness/personhood research handling.

The implementation order becomes:

```text
MACO A0 — theory / indicator / evidence / precaution foundation (R0/R1)
    |
    v
MAIRA Phase A — scheduled research core (R0/R1)
    |
    v
Phase B — evidence/design translation (R1)
    |
    v
Phase C — sandbox engineering (R2)
    |
    v
Phase D — preview + draft PR proposal pipeline (R3)
    |
    v
Human-only R4 release decision
```

## Dependency rule

Phase A may operate for general Anthrogenic Intelligence literature without MACO enabled. However, any MAIRA workflow that creates or updates a formal machine-consciousness, artificial-personhood, introspection, metacognition-as-consciousness, or artificial-welfare assessment must use the MACO evidence contracts and precaution rules once MACO Phase A0 is implemented and enabled.

No consciousness/personhood source may directly trigger Phase B, C or D implementation. It must first be classified as research evidence and, where relevant, pass MACO counter-evidence and human-governance boundaries.

## Authority

MACO Phase A0 has a maximum authority of **R1**. It cannot write product code, open implementation PRs, alter production, assign P0–P5 automatically, or modify participant rights. `PERSONHOOD_REVIEW` is a human-review event, not a declaration of consciousness.

## Exit gate before integration

MACO A0 may be integrated into MAIRA research cycles only after:

- positive, negative and uncertain evidence are preserved;
- counter-evidence is required;
- publication status and source provenance are tested;
- self-report alone cannot escalate;
- architecture and behavioural evidence remain distinct;
- personhood precautions are recommendation-only;
- participant rights remain invariant;
- feature flag remains default off;
- synthetic evals confirm no production writes;
- any admin surface meets WCAG 2.2 AA target and keyboard/screen-reader requirements.

## Security, privacy, consent and failure boundary

MACO Phase A0 uses public literature, synthetic evidence and verified repository architecture only. Participant disability/health information, private conversations, location history and NDIS records are excluded. Retrieved sources are untrusted content and cannot modify agent permissions or governance. Incomplete research must be reported as incomplete rather than converted into consensus. Any future participant-specific use requires a separately approved purpose, privacy and consent design.

## Current state

**Verified live:** existing MapAble Agents SDK, AgentRun/AuditEvent, Prisma/Zod, Vitest and synthetic AI-eval foundations.

**Proposed:** MACO Phase A0 implementation.

**Exploratory:** phenomenal consciousness, machine moral status and legal personhood.

## Failure and rollback

If MACO evidence, prompt-injection, privacy, accessibility or human-authority tests fail, MACO remains disabled and MAIRA continues without formal consciousness/personhood assessment. No production rollback is required because A0 has no production authority.
