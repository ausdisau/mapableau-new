# ProviderCloud

Hosted provider operations surface for `cloud.mapable.com.au`.

- MapAbleID service id: `providercloud`
- App route: `/providercloud` (cloud host root rewrites here)
- Status API: `GET /api/providercloud/status`
- Attention writers remain Care, Transport, Billing, Workforce, Continuity
- `MAPABLE_PROVIDER_OPS_ENABLED` stays default false
- Supplier operations are hard-disabled
- Not a premium listing or pay-to-rank product

See [provider-operations-cloud.md](./provider-operations-cloud.md) and
[productisation/PROVIDER_OPS.md](./productisation/PROVIDER_OPS.md).
