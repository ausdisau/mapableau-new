# Access LATER horizon (EXPLORATORY — preserve optionality)

Do not implement these now. Today's boundaries should not prevent them.

| Concept | Preservation mechanism |
| ------- | ---------------------- |
| A2A agent interoperability | Tool-safe deterministic services + actor/permission context |
| Agent discovery | Provider registry / config — no hard-coded agent endpoints |
| Accessibility Compass / XR / Around Me | Same underlying Access state; map is one presentation mode |
| Spatial audio + haptics | All guidance representable as text first |
| Robotic / LiDAR surveys | `ROBOTIC_SURVEY` contributor type; evidence with provenance only |
| Digital twins | MapAble remains accessibility intelligence overlay, not a general twin |
| Accessibility Uptime | Append-oriented evidence history + temporal fields |
| Predictive access fragility | Predictions must be distinguishable from observed fact |

Never put accessibility truth inside a rendering technology, agent protocol, or cloud vendor.
