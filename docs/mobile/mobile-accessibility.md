# Mobile accessibility

Component library in `apps/mobile/src/accessibility` and utilities in `@mapable/accessibility`.

Supports VoiceOver, TalkBack, switch access, keyboard, Dynamic Type / font scale to 200%+, high contrast, reduced motion, plain language, Easy Read, AAC prompt grid, TTS, and map list alternatives.

Touch targets target ≥ 48dp. No colour-only meaning. No gesture-only actions. Voice interpretation requires confirmation before consequential actions.
