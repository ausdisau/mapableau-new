# User testing plan (WS9)

## Goals

Validate the scoped AAA / ATAG claim with people with disability before any
unrestricted conformance statement.

## Participants (minimum)

- 2× screen-reader users (NVDA and/or VoiceOver)
- 1× keyboard-only / switch
- 1× low-vision / magnification / high contrast
- 1× cognitive / plain-language review of NDIS content + glossary

## Tasks

1. Find Care from the homepage; follow breadcrumbs; contact form.
2. Read `/accessibility-statement` and glossary; explain NDIS in own words.
3. (Staff) Create a geo layer with preview-before-publish; delete with confirm.
4. (Staff) Set coverage centre; confirm live announcement.
5. (Staff) Floor-plan draft with alt text; attempt submit without alt text.

## Output

Log issues to GitHub with labels `a11y` + surface. Update
`docs/accessibility/aaa-verification-checklist.md` when closed or accepted as
exceptions.
