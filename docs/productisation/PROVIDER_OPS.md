# Provider Operations Centre (read-only)

Flag: `MAPABLE_PROVIDER_OPS_ENABLED` (default false).

Hosted entry: ProviderCloud on `cloud.mapable.com.au` (`/providercloud` in this
app). The host is a read-only surface and does **not** enable this flag,
premium placement, or supplier operations.

Answers: what requires human attention today, why, who owns it, and what happens if unresolved.

Deep links point to Care, Transport, Billing, Workforce, and Continuity writers. This module does **not** create operational records.
