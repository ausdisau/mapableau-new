# Civic Accessibility Plan

**Target:** WCAG 2.2 AA

Wave 1 admin UI requirements:

- Semantic headings and table captions
- Keyboard-accessible controls (`PilotSeedPanel` button)
- List alternative to any future map (assets table)
- Source dates and claim states in text (not colour-only)
- Plain-language titles on assets
- No compulsory public account yet (no public Observatory)

Future Observatory must add no-JS essential fallbacks, Easy Read-ready consultations, captions/transcripts, and paper/telephone alternatives.
