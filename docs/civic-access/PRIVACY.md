# Civic Privacy Plan

## Classifications (Wave 1)

| Class | Examples | Wave 1 handling |
| --- | --- | --- |
| Public assets | Published places (future) | Not published |
| Operational asset data | Internal registry rows | Authenticated org/admin only |
| Participant missions / journeys | VisitPlan, CareOSMission | **Not accessed** |
| Synthetic pilot IDs | `harbour-*-demo` | Internal; not real people |
| Contributor identities | Future mappers | n/a |

Use synthetic journeys by default for planning analysis in later waves. Small-cell suppression required before any regional aggregates are published.
