# Civic Access Twin

**Status:** Roadmap (Wave 2+) — not implemented in Wave 1.

The Civic Twin is a versioned accessibility and journey **projection** over canonical sources. It is not a second asset-management system.

## Distinctions the twin must preserve

- Source asset vs MapAble canonical reference
- Imported geometry vs verified access evidence
- Venue attestation vs community observation
- Current sensor state vs derived incident vs simulated future state

## Wave 1 precursor

`CivicAssetVersion.projectionSnapshot` and `projectStaticAccessibility()` provide a static claim projection only.
