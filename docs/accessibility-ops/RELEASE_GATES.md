# Release gates

All gate flags default **false**:

- `MAPABLE_ACCESSIBILITY_GATE_WEB_RELEASES`
- `MAPABLE_ACCESSIBILITY_GATE_MOBILE_RELEASES`
- `MAPABLE_ACCESSIBILITY_GATE_DOCUMENTS`
- `MAPABLE_ACCESSIBILITY_GATE_VENUE_GUIDES`
- `MAPABLE_ACCESSIBILITY_GATE_PARTNERS`

Wave 1 shadow evaluation sets `blocking: false` always. Emergency exceptions (later) require human approval — never models or commercial deadlines.
