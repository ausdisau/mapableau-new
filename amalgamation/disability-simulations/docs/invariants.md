# Simulation invariants

Shared clinical-education doctrine for the disability-simulations SoR.

```text
communication failure != incapacity
disability != acute deterioration
model proposal != clinical truth
equipment availability != indication
```

- AAC composition **pauses** simulation time.
- Authority transfer must never follow from communication failure alone.
- MapAble CareOS Life Twin (platform SoR) is **participant support simulation**, not this education runtime.

See also: platform docs `docs/careos/LIFE_TWIN.md` and
`docs/strategy/AUSDISAU_AMALGAMATION.md`.
